ClassicCombatLog - build without installing anything
1. Create a free GitHub account, make a new repository, upload everything in this folder
   (keep the .github/workflows folder).
2. Open the Actions tab -> "Build ClassicCombatLog.dll" -> wait for the green check.
3. Download the "ClassicCombatLog" artifact, unzip it.
4. Put ClassicCombatLog.dll in Fallout New Vegas\Data\NVSE\Plugins\  (needs xNVSE installed).
No .esp. Not tested in-game yet: see the [VERIFY] notes in the .cpp.
